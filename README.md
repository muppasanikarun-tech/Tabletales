# TabletTales — GitHub + Vercel

A static, responsive single-page concept site for TabletTales.

## Deploy
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. In Vercel, choose **Add New → Project**, import the repository, and deploy.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (root). No environment variables are required.

## Included simulations
- Venue selector: The Wall Brewery, Little Fern Café and Northstar Coffee, each with a sample table number.
- Sample menu categories and add/remove cart controls.
- Order submission preview, illustrative ETA, service request buttons and bill preview.
- Venue-specific My Brewery Story / My Cafe Story / My Coffee Story.
- Local image preview and story caption card. Photos are not uploaded to a server.
- Business enquiry form opens the visitor's email app with a prefilled message.
- Four 60-day roadmap phases beginning 28 January 2027.

## Before going live
- Replace `hello@tabletales.in` in `index.html` with an inbox you actively monitor.
- The venue/table identity, orders, ETA, staff alerts, payments, photo sharing, likes and leaderboard are demo-only. They do not connect to a POS, kitchen, waiter device, database or TV.
- To make the enquiry form reliably collect leads, connect it to a backend/form service; `mailto:` depends on the visitor having an email app configured.
- Add privacy notice, consent controls, moderation, security, accessibility testing and venue-specific menus before a production launch.
